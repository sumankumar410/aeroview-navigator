# ✈️ Aero Spark — Frontend Application

Modern React 18 + Vite frontend for the Aero Spark Aircraft Maintenance & Airworthiness System, written in standard JavaScript (`.jsx` / `.js`).

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS, PostCSS, Framer Motion
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Charts & Data**: Recharts, TanStack React Query
- **UI Components**: Radix UI (shadcn/ui), Lucide Icons, Sonner

## Setup & Running

```bash
# Install dependencies
npm install

# Start Vite dev server (runs on http://localhost:8080)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Demo Credentials
- **User / Flight Operator**: `user` / `user123` (Redirects to `/flight-status`)
- **Administrator**: `admin` / `admin123` (Redirects to `/dashboard`)
